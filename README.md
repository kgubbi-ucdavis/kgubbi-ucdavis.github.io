# Kevin Immanuel Gubbi — Personal Portfolio

Personal website for Kevin Immanuel Gubbi, Co-Founder & CTO of ChipSage Labs.

Built with plain HTML, CSS, and JavaScript. Hosted on GitHub Pages.

**Live site:** [kgubbi-ucdavis.github.io](https://kgubbi-ucdavis.github.io)

## Good Reads

`reading/` is a curated reading library served at [/reading/](https://kgubbi-ucdavis.github.io/reading/).

- `reading/resources.js` holds the catalog (categories, resources, reading paths, people). Add or edit entries there; no layout changes are needed.
- `reading/reading.js` renders the page and handles search, category filters, and `#category` / `#r-<id>` links.
- `reading/reading.css` contains page-scoped styles built on the tokens in `css/style.css`.

Update `lastUpdated` in `resources.js` when the collection changes.
